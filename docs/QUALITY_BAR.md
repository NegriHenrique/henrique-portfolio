# Quality Bar

A feature is only complete when:

- visual coherence is preserved
- editorial rhythm remains intact
- mobile experience feels intentional
- no visual noise was introduced
- spacing remains breathable
- motion feels restrained and purposeful
- accessibility remains intact
- Lighthouse remains ≥ 95
- implementation remains understandable
- no unnecessary abstraction was introduced

Technical correctness alone is insufficient.

If the experience:
- feels generic
- feels crowded
- feels inconsistent
- feels over-engineered
- feels visually noisy

the feature is not complete.
